# 🐧 Projeto Pinguins - Estudo de HTML5 e CSS3

Repositório criado para praticar a estruturação de sites informativos utilizando boas práticas de desenvolvimento web.

## 🛠️ Tecnologias e Conceitos * **HTML5 Semântico**: Uso de tags como <abbr> para tooltips e listas para organização. * **Hierarquia de Títulos**: Aplicação correta de h1 e h2 para organização de conteúdo. * **CSS3**: Estilização de elementos e gestão de layout. * **Git**: Gestão de repositório e controle de versão.

## 🚀 Objetivo Demonstrar a evolução no aprendizado de Front-end, focando em organização de pastas e clareza de código.
